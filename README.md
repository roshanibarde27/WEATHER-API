Weather API Project 🌦️

Introduction

This is a Weather Forecast project built using HTML, CSS, JavaScript, and JSON Server. It displays weather information for different cities in the form of cards.

Features

- Displays city names and weather information.
- Shows temperature, weather condition, humidity, and wind speed.
- Displays an image for each city.
- Uses JavaScript Fetch API to get data from JSON Server.
- Presents weather details in a card layout.

Technologies Used

- HTML
- CSS
- JavaScript
- JSON Server

Project Files

- "1_db.json" – Stores the weather data.
- "2_index.html" – Contains the HTML structure.
- "3_style.css" – Contains the styling of the weather cards.
- "4_main.js" – Fetches the data and displays weather cards.
- "package.json" – Contains project information.

How to Run the Project

1. Open the project folder in VS Code.

2. Open the terminal in the project folder.

3. Run the following command:
   
   "npx json-server --watch 1_db.json"

4. JSON Server will start on port 3000.

5. Open the HTML file using Live Server to view the project.
